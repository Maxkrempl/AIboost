# Landing Page Copy for Portfolio ( four apps )

This document contains the go-to-market landing copy for EtsyBooster, SEOBooster, MenuBoost and GEOBoost. Each app section includes a hero, subheading, core features, call to action, social proof placeholder, and a simple FAQ.

## 1) EtsyBooster

### Hero
Unlock Etsy visibility in seconds with AI-powered listing optimization.

### Subheadline
AI-generated titles, descriptions and tags—no signup required. Free to try.

### Key value propositions
- Save hours composing SEO-optimized listings
- Improve search rankings on Etsy
- Quick, repeatable listing quality across products
- Multilingual or locale-aware options if required

### Features
- AI-generated SEO titles (under 140 characters)
- Descriptions (200-280 words)
- Up to 13 relevant tags
- 10-second turnaround per listing
- Free to try; Gumroad-based paid plans later

### CTA
Get your first optimized listing now (no signup required)

### Social proof placeholder
"Loved by early Etsy sellers" – testimonials coming soon

### FAQ (quick)
- Do I need an account? No — free to try on EtsyBooster.
- How many listings can I optimize? Per listing; varies by tier later.
- What languages are supported? Multi-language support in future updates.
