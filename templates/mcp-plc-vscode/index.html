Quick Start

Up and running in 30 seconds

One command. Any PLC. AI reads your sensors.

Terminal Run 
# Install once
$ npm install mcp-plc-core

# Run with any PLC
$ PLC_HOST=192.168.1.100 npx mcp-plc --adapter modbus
$ PLC_HOST=192.168.1.100 npx mcp-plc --adapter s7
$ npx mcp-plc --adapter ./my-plc.js

MCP Tools

6 tools. Full PLC access.

Read sensors, check alarms, control setpoints — all through natural language.

ToolDescriptionExample
read_sensor Read any sensor value from the PLC "What's the temperature?"
get_alarms Active alarms with priority and recommended action "Any alarms active?"
get_status Full system status in one call "How's the line running?"
get_setpoints Current setpoint values from the PLC "What are the setpoints?"
write_setpoint Write setpoints with safety limits validated "Set temperature to 35°C"
get_all Everything at once — complete PLC snapshot "Give me all data"
Safety

Built for production environments

Industrial-grade safety by design, not afterthought.

🔒

Read-Only Default

No writes happen without explicit tool call. Safe by default.

🛡️

Safety Limits

Configurable min/max per setpoint. Out-of-range values rejected instantly.

📋

Audit Logging

Every tool call logged. Full traceability for compliance.

🔌

Adapter Isolation

Protocol errors stay in the adapter. Clean error boundaries.
